# Mihomo и WARPSCOUT

Python и curl устанавливаются пакетным менеджером системы. Mihomo и WARPSCOUT
не входят в этот репозиторий. Нужны именно бинарники для архитектуры вашей машины.

- [Mihomo 1.19.24](https://github.com/MetaCubeX/mihomo/releases/tag/v1.19.24) —
  проверенная версия ядра. Выберите Linux-сборку для своей архитектуры и CPU;
  расширенные amd64 v2/v3-сборки подходят не всем процессорам.
- [WARPSCOUT 0.16.0](https://github.com/vernette/warpscout/releases/tag/v0.16.0) —
  проверенная версия регистрации и поиска. Нужны `register`, `scan`, `-through`
  и `-conf-type mihomo-json`.

Распакуйте скачанные архивы и проверьте опубликованные авторами контрольные
суммы, если они предоставлены. Из каталога с распакованными бинарниками:

```sh
sudo install -m 755 ./mihomo /usr/local/bin/mihomo
sudo install -m 755 ./warpscout /usr/local/bin/warpscout
mihomo -v
warpscout version
```

Если архив содержит файл с длинным именем, укажите его фактическое имя вместо
`./mihomo` или `./warpscout`. Каталог `/usr/local/bin` должен быть в `PATH`.
Можно использовать пакет дистрибутива подходящей версии; не запускайте его
штатную службу одновременно с нашей службой на тех же портах и ключах.

На Void musl нужен бинарник, совместимый с musl, статический бинарник или
сборка из исходников. Название «linux-amd64» само по себе совместимость с musl
не подтверждает. Python-код warp-vpn не использует нативных расширений,
но это не меняет требований его внешних зависимостей.

На NixOS используйте Mihomo из `pkgs.mihomo`. WARPSCOUT можно держать в
`~/.local/bin`; Nix-модуль его автоматически не скачивает и не регистрирует аккаунт.
